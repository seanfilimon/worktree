# W0rkTree Engineering Plan & Contracts (v2 rebuild)

This document is the **binding contract** for the v2 rebuild. Every
workstream codes against the interfaces here. If you must change a contract,
keep the change additive and note it in your final report.

## 1. Target architecture

```
 wt (CLI, Rust) ──► worktree-sdk (Rust) ──► .wt/ on disk
      │                  │  remote (gRPC h2c + REST)
      │ ipc (JSON/TCP)   ▼
 worktree-bg (Rust) ──► worktree-server (Go, services/server-go) ──► bbolt meta + CAS objects
                              ▲ REST + SSE
                        apps/admin (React/Vite admin panel)
 worktree-git (Rust) — Git import/export over worktree-sdk
 apps/web (Next.js) — marketing + docs site
```

* **One server port** (default `7420`): gRPC (`application/grpc*`, HTTP/2
  cleartext h2c) and REST/SSE/static share it. Remote URLs look like
  `http://localhost:7420`.
* The Rust `crates/worktree-server` crate was **removed** (superseded by Go).
* The Yew `crates/worktree-admin` crate is **replaced** by `apps/admin`.

## 2. Wire protocol

`crates/worktree-protocol/proto/sync.proto` (`worktree.sync.v1.SyncService`)
is the Rust⇄Go contract. Regenerate Go code with `bash scripts/gen-proto.sh`;
Rust code is generated by `build.rs` (vendored protoc, no install needed).

* **Object hash** = BLAKE3-256 of exact bytes. `ContentHash.value` = 32 raw bytes.
* **Objects**: BLOB = raw file bytes; MANIFEST = protobuf-encoded
  `ManifestRecord` (entries sorted by path, unique, '/'-separated).
* **Snapshots** travel as `SnapshotRecord` (not objects). ids = UUID v4 strings.
* Auth: gRPC metadata `authorization: Bearer <token>`; anonymous allowed only
  for Ping and reads of public trees.
* **Push flow**: `ResolveTree(create_if_missing)` → `Pull`/`ListBranches` to
  learn remote tip → `UploadObjects` (manifests + blobs the server lacks; use
  `Negotiate` with `have` = candidate hashes, response `objects_to_send` =
  hashes the server is missing) → `Push{old_tip, new_tip, snapshot_chain,
  snapshots}`. Server checks: auth (tree:write), review.CheckPush, license
  CheckPush on changed paths, all referenced manifests/blobs present, every
  snapshot's parents known (already stored or in this request), new_tip
  descends from current server tip (else `ConflictDetected{server_tip}`), CAS
  on branch tip. On success clears pusher's staged entry for the branch,
  publishes `branch.pushed`, audits `branch.push`.
* **Pull flow**: `Pull{current_tip}` → server returns `snapshot_chain` +
  `snapshots` (missing ones, oldest first, `depth` limits count) and
  `objects_to_fetch` (all manifest + blob hashes referenced by those
  snapshots) → client `DownloadObjects(want = hashes it lacks)`.
* gRPC max message size: 64 MiB both directions.

## 3. Local repository layout (`.wt/`)

See the doc comment in `crates/worktree-sdk/src/repo/mod.rs` (authoritative).
Per-user state lives in `$WT_HOME` (default `~/.wt`): `credentials.toml`,
`bg.json`, `bg.toml`, `bg.log`. **Tests must set `WT_HOME` to a temp dir.**

`.wt/config.toml` = `worktree_sdk::config::WorktreeConfig`
(`[worktree]`, `[user]`, `[auto_snapshot]`, `[sync]`, `[remote.<name>]{url, tenant}`).

Built-in ignores: `.wt/`, `.wt-tree/` (marker dirs), `.git/`, `target/`,
`node_modules/`, `.DS_Store`, `*.swp`, plus `.wt/ignore` and `.wtignore`
(gitignore syntax via `worktree_protocol::feature::ignore`).

## 6. Background daemon (`worktree-bg`)

Binary `worktree-bg` (`run [--foreground]`). IPC per `worktree_sdk::ipc`.
Config `$WT_HOME/bg.toml` `{ watched = ["path", ...] }` persisted on watch/unwatch.
Per watched worktree: `notify` watcher → debounce (`[auto_snapshot]`
inactivity / max files) → `Repository::snapshot(auto_generated=true,
message="auto: N files changed")` for each tree with changes → if
`[sync].auto_stage` and remote + credential exist, `remote::stage`.
Never snapshots during a merge in progress. Ignores events under `.wt/`.

### Server config (flags / env)

`--addr` / `WT_ADDR` (default `:7420`), `--data` / `WT_DATA` (default
`./wt-data`; holds `meta.db` + `objects/`), `--admin-user`/`WT_ADMIN_USER`

served at `/admin/`), `--allow-registration`/`WT_ALLOW_REGISTRATION` (default true),
`--log-level`.

## 9. Conventions

* Rust: edition 2021, `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings` must pass for your crate. No `unwrap()` on I/O in library code.
* Go: `gofmt`, `go vet ./...`, table-driven tests, `t.TempDir()`. Pure Go only (no cgo). Allowed deps: grpc, protobuf, `go.etcd.io/bbolt`, `golang.org/x/crypto`, `golang.org/x/net`, `github.com/google/uuid`, `github.com/zeebo/blake3`.
* Windows is a first-class platform (this repo is developed on Windows): no hardcoded `/tmp`, handle `\` paths, atomic renames may fail with "Access is denied" when the target exists — treat as success if content-addressed.
* Never use `git` to commit in the shared root; commit only inside your own worktree/branch.

## 11. v0.3 admin expansion

### 11.1 New REST endpoints

All under `/api/v1`, same envelope/auth/error rules as §7. `REV` = snapshot
id (full or unique prefix ≥ 4), branch name or tag name of the tree.
`{tree}` below = `/api/v1/trees/{tenant}/{tree}`. Owner in brackets.

```
[go-insights]
GET  {tree}/compare?to=REV&from=REV&context=3   -> CompareResult       (tree:read; from defaults to to's first parent; no parent -> from null, all files added)
GET  {tree}/history?path=P&branch=B&limit=50     -> [FileHistoryEntry]  (tree:read; snapshots on branch's history that changed P, newest first)
GET  {tree}/stats?branch=B&days=30              -> TreeStats           (tree:read; days 1..365)
GET  {tree}/staged/summary                      -> [StagedBranchActivity] (tree:read; staged.Service.Summary)
GET  /events/recent?tenant=&tree=&limit=50       -> [Event] oldest first (same authz/scoping as GET /events; bus Recent)

[go-manage]
POST   {tree}/branches        {name, from?}                -> 201 Branch   (branch:create; from = REV, default default-branch tip; 409 exists; publishes branch.created; audit branch.create)
DELETE {tree}/branches/{name...}                           -> 204          (review.CheckDeleteBranch; audit branch.delete)
POST   {tree}/tags            {name, target, message?}     -> 201 Tag      (tree:write; target = REV; 409 exists; publishes tag.pushed)
DELETE {tree}/tags/{name}                                  -> 204          (tree:admin)
PATCH  /tenants/{tenant}      {name?, plan?}               -> Tenant       (tenant:admin; plan requires server admin)
POST   /auth/password         {current_password, new_password} -> 204      (self; revokes the caller's other session tokens)
POST   /admin/accounts        {username,email,password,is_admin} -> 201 Account (server admin; bypasses allow_registration)
POST   /admin/accounts/{username}/password {password}      -> 204          (server admin; revokes that account's tokens)
GET    /admin/system                                       -> SystemInfo   (server admin)
GET    /search?q=&limit=20                                 -> SearchResults (signed in; case-insensitive substring on tenant slug/name, tree name/description, branch name, account username/email; only what the caller can read; accounts for server admins only)
```

JSON shapes are the TypeScript interfaces at the end of
`apps/admin/src/api/types.ts` (FileDiff, CompareResult, FileHistoryEntry,
TreeStats, StagedBranchActivity, SystemInfo, SearchResults) — field names
there are authoritative. Diff rules: text files only (binary = NUL in first
8 KiB or invalid UTF-8); a side > 1 MiB → `too_large: true`, no patch;
patches are unified diffs with `--- a/P` / `+++ b/P` headers (`/dev/null` for
added/deleted). CompareResult.files sorted by path. Languages in TreeStats are
detected by file extension (top 10 by bytes, rest "Other").

### 11.2 Admin panel design rules

* **Monochrome only.** Black, white and neutral greys (`src/index.css` tokens).
  No hue anywhere — not for success/error/warning, not in charts. Express state
  with weight, inversion (filled vs outline badges), icons (lucide-react),
  borders, strike-through and labels.
* **shadcn/ui everywhere.** Use `@/components/ui/*` (Button, Card, Badge,
  Table, Tabs, Dialog, AlertDialog, DropdownMenu, Sheet, Sidebar, Command,
  Tooltip, Skeleton, Select, Input, Textarea, Switch, Checkbox, Chart,
  Breadcrumb, ScrollArea, Sonner...). Add missing primitives with
  `npx shadcn@latest add <name>` (never edit existing generated files beyond
  trivial fixes; never re-add/overwrite existing ones). Icons: `lucide-react`.
  Class merging: `cn` from `@/lib/utils`.
* `src/components/legacy/*` is deprecated; pages being rebuilt must stop using
  it. It is deleted at integration.
* Toasts: keep the `useToast()` hook API in `src/toast/` stable (backed by
  Sonner after the shell rebuild).
* Dense, professional, keyboard friendly; Inter + JetBrains Mono; tables with
  sticky headers; empty states, skeletons; responsive to 375 px.
* Tests: vitest + Testing Library; each page keeps or gains coverage.
