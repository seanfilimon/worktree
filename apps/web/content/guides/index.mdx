These guides walk through real tasks end to end. They cover W0rkTree **v0.2.0** ("v2 rebuild"): the `wt` CLI, the `worktree-bg` background daemon, the Go server, and the admin panel. For exact command and API references, see the [Docs](/docs).

<Callout type="info" title="Pre-1.0">
  W0rkTree is pre-1.0 and is built from source. See [Installation](/docs/installation) before you start.
</Callout>
